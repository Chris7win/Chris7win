Projects span two domains — now integrating both.

**Embedded & IoT** — Sensor systems, autonomous rovers, safety-critical hardware, real-time data pipelines over MQTT. Bare-metal and HAL-level firmware on ESP32, Arduino, and Raspberry Pi.

**Web & App** — Full-stack dashboards, REST APIs, mobile apps with Flutter. End-to-end, from database schema to UI.

**Now** — Merging them. Systems where hardware talks directly to the web: live sensor feeds, cloud dashboards, cross-platform apps that respond to the physical world in real time.
